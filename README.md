# ADHIKARAI – Agentic AI Government Scheme Navigator

## Overview
Millions of Indian citizens are unaware of government welfare schemes they are eligible for. Information is scattered across multiple websites, and eligibility criteria are complex.

ADHIKARAI is an AI Agent that interacts with users in natural language, understands their profile, determines eligibility, recommends schemes, guides document preparation, tracks applications, and answers scheme-related questions.

## Tech Stack
* **Frontend**: React.js (Vite), Material Design
* **Backend**: Node.js, Express.js
* **Database**: MySQL (Railway Cloud)
* **AI Module**: Python, FastAPI, OpenAI LLM API, Sentence Transformers, LangChain
